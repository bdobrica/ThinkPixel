# Hybrid search for WordPress

**Component:** [ThinkPixelSR / ThinkPixelInfra](https://github.com/bdobrica/ThinkPixelInfra)
**Status:** standalone / existing

The first practical ThinkPixel lineage is a search and retrieval system intended to move WordPress search beyond lexical coincidence.

The architecture separates WordPress integration from search infrastructure and supports semantic/vector retrieval alongside lexical search signals, preserving exact-match behavior while improving retrieval based on meaning and intent.
