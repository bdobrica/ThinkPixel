# ThinkPixel Use Cases

This directory documents concrete applications of the ThinkPixel ecosystem.

Each use case should describe:

- the problem being solved;
- participating ThinkPixel components;
- the end-to-end flow;
- trust and governance boundaries;
- current implementation status;
- links to runnable examples or evidence where available.
